# Saymore Office

Public website for [Saymore](https://github.com/PraxisGrove/Saymore), built with Next.js App Router and configured for Vercel.

## Development

```bash
pnpm install
pnpm dev
```

## Verification

```bash
pnpm check
pnpm typecheck
pnpm build
```

Product claims and visual rules are documented in `PRODUCT.md`, `DESIGN.md`, and `brand-spec.md`.
